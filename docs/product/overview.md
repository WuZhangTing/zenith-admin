# 产品概览

Zenith Admin 是一个面向企业后台、运营平台和内部工具场景的全栈后台管理系统。

## 核心定位

它的定位不是"做一个空白管理台壳子"，而是提供一套已经具备基础管理能力、并且适合继续扩展的项目底座。

适合这些团队：

- 想快速上线后台系统的创业团队
- 需要统一技术栈和代码规范的中小团队
- 需要做客户演示、PoC 或内部运营工具的项目组

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 运行时 | Node.js 24 |
| 后端 | Hono v4（`@hono/zod-openapi`） |
| 前端 | React 19 + Vite 8 |
| UI | Semi Design v2 + lucide-react |
| 服务端状态 | TanStack Query v5 |
| ORM | Drizzle ORM |
| 数据库 | PostgreSQL |
| 缓存/会话 | Redis（ioredis） |
| 任务调度 | pg-boss |
| 实时通信 | WebSocket + SSE |
| 校验 | Zod 4（前后端共享 schema） |
| 认证 | JWT（Access + Refresh 双 Token） |
| 桌面客户端 | Electron |

## 应用形态

前端提供三个独立入口，配合可选的桌面与离线形态：

- **后台管理**（`index.html`）：管理员使用的完整后台
- **前台会员 SPA**（`member.html`）：面向 C 端会员的独立单页应用，移动优先
- **移动审批轻页**（`approval.html`）：不加载后台框架的轻量审批入口
- **PWA / Electron**：可选启用 PWA 添加到主屏幕，或打包为桌面客户端
- **Demo 演示模式**：`VITE_DEMO_MODE=true` 时通过 MSW 拦截全部 API，无需后端即可完整演示

## 产品价值

### 降低初始化成本

用户、角色、菜单、部门、岗位、字典、文件管理等后台常见模块已经具备基础能力，不必每个项目都重头搭建。

### 内置工作流引擎

可视化流程设计器（审批/抄送/条件分支/延迟器/触发器/子流程）、表单库与自定义业务表单、业务系统接入（businessKey 关联外部实体）、流程模板、审批代理、定时发起、连接器、流程自动化与事件总线、引擎健康巡检与移动审批轻页，无需引入外部引擎即可覆盖大多数审批场景。

### 即时通讯开箱可用

基于 WebSocket 的单聊/群聊、消息回复/撤回/编辑/转发、@提及、投票、语音消息、WebRTC 音视频通话、收藏置顶等能力，快捷聊天可在任意页面唤起。

### 多渠道通知体系

站内信、公告推送、邮件（SMTP）、短信（多服务商）、消息频道（运营号：订阅、群发、自动回复、客服工作台）均已落地，并配备模板管理与发送日志。

### 安全能力全链路覆盖

JWT 双 Token + 会话黑名单 + 登录失败锁定 + IP 黑白名单 + 数据脱敏 + 幂等防重复提交 + 接口限流，并支持身份安全策略、登录风险事件与企业身份源（OIDC / SAML / LDAP / AD）单点登录，满足企业级后台安全合规要求。

### AI 功能区

内置多服务商 AI 对话（SSE 流式）、知识库 RAG（文档向量化检索）、自定义智能体、HTTP 工具（函数调用）、模型评测与竞技场、提示词模板、用量统计与对话审计，用户可按需配置自己的模型密钥；工程结构配合 Zenith Skill 可通过 AI 指令快速生成 CRUD 模块。

### 支付中心开箱即用

多渠道支付通道配置（微信支付 / 支付宝等）、支付订单生命周期管理（下单/支付/关闭/退款）、预授权、签约代扣、支付链接，配套对账中心、资金台账、费率/结算/分账/转账、风控与交易投诉、财务报表；outbox 事件表保证支付事件可靠投递，可直接接入业务系统。

### 会员体系全覆盖

前台 C 端（`member.html` 独立 SPA）与后台管理系统双轨并行、彻底隔离。后台提供会员看板、会员管理、等级体系、积分账户、钱包余额（乐观锁防并发超扣）、充值记录、优惠券、签到与里程碑奖励，前台支持手机号验证码、手机号 / 邮箱 / 用户名密码登录与会员自助。

### 报表中心自助取数

多源接入（API / MySQL / PostgreSQL / SQL Server / Excel·CSV）、数据集加工、仪表盘与数据大屏、类 Excel 打印报表、智能问数（NL2SQL / ChatBI）、指标中心、数据质量、数据填报、数据预警与分享订阅，对标积木报表的自助式报表平台。

### CMS 内容管理

多站点与树形栏目、内容模型与富文本编辑、素材中心、可视化页面搭建、静态化发布、全文检索、SEO、评论/广告/表单/问卷、敏感词与采集中心、内容分发与会员订阅，覆盖内容型站点的完整生产链路。

### 规则中心沉淀业务规则

决策表（多种命中策略、版本管理、测试用例与影子运行）、决策流编排、黑白灰名单库与执行记录，让风控和业务规则脱离硬编码。

### 开放平台对外输出能力

开发者自助应用、生产/沙箱环境、OAuth 2.1（PKCE）、HMAC 签名网关、API Scope 与限流套餐、调用统计、Webhook 订阅与在线 API 调试台。

### 数据分析与错误监控

内置行为埋点采集（PV/UV/停留/点击）、指标大盘展示与多维筛选；前端 JS 异常自动上报，错误堆栈一键查看，无需额外接入 APM 工具。

### 一站式系统运维

Web SSH 终端（多分屏）、SSH 配置与 SFTP、终端录屏回放、服务器文件管理器、进程管理、端口监听、Docker 容器管理、systemd 服务管理、防火墙 / Nginx 站点 / SSL 证书管理、网络诊断、日志查看器——运维操作不必离开管理后台；配合服务监控、监控告警、任务中心、导出中心与维护模式形成完整可观测闭环。

### 保持演进空间

`shared` 层统一类型、常量和 schema（按业务域拆分子路径导入），适合在新增业务时保持前后端一致性。

### 面向团队协作

接口规范、分页格式、页面布局、时间处理方式等都已经形成约定，适合多人协作开发。
