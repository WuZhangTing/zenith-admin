# 运营与治理

面向管理员的三个治理页面：用量统计、AI 反馈、对话审计。

---

## 用量统计

页面菜单路径 `/ai/usage`（权限 `ai:usage:view`）：

- 按日期趋势统计消息数、Token 消耗与预估成本（成本按服务商配置的输入 / 输出单价估算）；
- 按**模型**与**用户**分组聚合；
- 支持日期范围筛选（默认近 30 天）。

助手消息落库时记录生成模型、输入 / 输出 Token、首字延迟（`ttft_ms`）、总耗时与调用链 `trace`；上游未返回 usage 时按字符数估算兜底。

## 反馈闭环

页面菜单路径 `/ai/feedback`（查看 `ai:feedback:view`，处理 `ai:feedback:handle`）：

1. 用户在对话中点赞 / 点踩（点踩可选原因：不准确 / 不相关 / 有害 / 其他）；
2. 管理员按反馈类型、处理状态（待处理 / 已处理 / 已忽略）、日期范围筛选；
3. **上下文回放**复用聊天渲染组件（思维链 / 图片 / 工具调用 / 知识库引用 / 模型标注与对话页一致），目标消息高亮；
4. 处理后更新状态并可填写备注；支持导出。

## 对话审计

页面菜单路径 `/ai/audit`（权限 `ai:audit:view`）：

- 跨用户检索全量 AI 消息（按角色、日期范围、关键词过滤）；
- 上下文回放同样复用聊天渲染组件，含工具调用、知识库引用与发送人（用户名 / 昵称 / 头像）；
- 管理端敏感操作（服务商 / 工具 / 数据集变更等）写入系统操作日志。
